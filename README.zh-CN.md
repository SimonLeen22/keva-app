> **你的安卓手机，就是 AI 助手的电脑。**

**Claude Code** 和 **Codex** 在手机上跑，模型由你选。它能处理文件，用上手机的定位和视频硬件，经你授权还能操作别的 App。不用电脑，不用 root，也不用云桌面。

**当前 Android 版本为 2026.43.7**，可从 [keva.chat/download](https://keva.chat/download/) 下载。本版修复了安卓不再接受可行保存的配对时，手机助手设置卡在第 6 步的问题。上一版 2026.43.6 让可行手机助手在复杂页面上稳定运行、任务结束后自动回到可行，新增分步显示的悬浮胶囊和任务通知，出错时统一用一张卡片说明原因和可做的操作，并支持 Kimi K3.1 Pro 与 MiniMax M3.1-Flash。历次版本见[更新日志](CHANGELOG.md)，关注本仓库可获取版本动态和公开文档。

## 手机凭什么能干这些

| | 这意味着什么 |
|---|---|
| **手机就是那台电脑** | 可行把 shell、文件、Git、Python、Node 和 ffmpeg 放进手机，让 AI 助手有地方干活。它不跑桌面软件，只给 AI 助手配齐工具。 |
| **完整的 AI 助手，模型你挑** | 内置官方 Claude Code 和 Codex。AI 助手在手机上跑，模型在你选的服务商那里，请求直接发过去，不经过可行。 |
| **用上手机的定位和视频硬件** | 经你授权，地图类任务能用上你所在的位置，坐标不记录。剪视频时用手机自己的硬件解码、编码，1080p 成片在手机上做出来。 |
| **替你操作别的 App，你说了算** | 在同一部手机上，把系统自带的无线调试和可行配对一次，它就能看屏、点按、滑动、输入。悬浮胶囊显示每一步，随时接手或停止。 |

## 今天想让手机替你做点什么

- **处理文档**：周报、合同、表格，帮你写好、改好，改到能直接发出去。「整理成周报，三段，每段不超过 100 字，别太官腔。」
- **写代码**：做个小工具，或者把跑不起来的程序修好。「帮我做个记账的小网页，能按月看支出。」
- **剪视频**：几段素材，剪成一支能发的短片。「剪 30 秒，配轻一点的音乐，开头放海，结尾放雪。」
- **操作 App**：你授权之后，它在别的 App 里替你点、替你滑、替你填。「帮我查下周三上海到东京的机票，最便宜的那班。」

## 看 AI 助手在手机上怎么干活

1. **一句话，做出一个能玩的俄罗斯方块**：从空白开始，它写代码、自己检查、自己改，最后在手机浏览器里当场玩起来。
2. **几段旅行素材，剪成一支 30 秒短片**：它先看一遍素材，再按你说的节奏剪、配乐、加字幕，最后输出成片。
3. **让它打开携程，帮你查机票**：说清楚从哪到哪、哪天走，它自己打开 App、点进航班列表，把航班和价格给你看；你随时可以接手或停止。

可在 [可行官网](https://keva.chat/zh/#watch) 观看演示。

## 模型与接入方式

- **Claude Code**：登录 Claude 账号，或使用 API Key / 服务商。
- **OpenAI Codex**：登录 ChatGPT 订阅，或填写 OpenAI API Key。
- **更多服务商**：DeepSeek、GLM、Kimi、LongCat、MiniMax、Qwen、小米 MiMo，另可自填一个兼容 Anthropic 的接口。

Claude 与 Codex 之间切换时，当前对话上下文会被保留，不必从头交代工作。

## 文件留在手机里，对话直接发给模型服务商

文件、聊天记录和模型 API 密钥都存在手机上。你发给它的话，和它干活时用到的文件，直接发给你选的模型服务商，不经过可行。操作 App 工作期间，屏幕内容也会发给你选的模型服务商。会发到可行这边的只有两样：一次匿名的版本检查，和登录或购买时激活要用的账号、授权、支付与设备信息；银行卡由 Paddle 处理。我们不装追踪器，也不统计你的使用。

## 反馈与安全

- 查看 [常见问题](docs/FAQ.zh-CN.md)。
- 使用 Issue 模板提交可复现的问题或功能建议。
- 如果 Keva 意外退出，下次打开会弹出崩溃摘要：点「**复制详情**」（或在「**设置 › 运行诊断**」里查看保留的上次报告），粘贴到问题反馈里即可。报告由错误类型、App 操作步骤和设备信息组成，设计上不包含你的对话内容。
- 提交公开反馈前请阅读 [CONTRIBUTING.md](CONTRIBUTING.md)。
- 安全漏洞请遵循 [SECURITY.md](SECURITY.md)，不要公开提交 Issue。
