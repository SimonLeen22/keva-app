# Security policy

Please do not report security vulnerabilities in a public GitHub issue.

Send a concise report to [hello@keva.chat](mailto:hello@keva.chat) with:

- a description of the issue and its impact;
- clear reproduction steps;
- the Keva version and Android version involved;
- any suggested remediation, if available.

Do not include API keys, account credentials, private files, or personal data. We will acknowledge a valid report and coordinate a fix before public disclosure.
