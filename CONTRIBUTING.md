# Feedback and contributions

Keva's application source code is closed. This repository does not accept source-code pull requests.

You can still help improve Keva:

- Open a bug report with clear reproduction steps, expected behavior, and what happened instead.
- Open a feature request that explains the problem you are trying to solve.
- Keep private information, API keys, prompts, files, and screenshots with sensitive content out of public issues.

For a security vulnerability, follow [SECURITY.md](SECURITY.md) instead of opening an issue.
